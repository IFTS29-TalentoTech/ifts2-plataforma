# ADR-045 — Instagram: los dos tipos de token, "Probar conexión" paso a paso y carga manual por enlace

- **Estado:** aceptada (08/11/2026). Reemplaza la parte de ADR-043 que pedía pegar la dirección de la imagen y corrige el supuesto de ADR-009/044 de que solo servían tokens de «Instagram con inicio de sesión de Instagram».
- **Contexto:** el token nuevo del cliente empieza con `EAA` (Facebook Login) y Meta respondía HTTP 400, código 190, «Cannot parse access token». Nuestro cliente mandaba todo a `graph.instagram.com`, que solo entiende tokens `IG…`. Además Instagram no deja copiar la dirección de la imagen (solo el enlace de la publicación), así que la carga manual descrita en ADR-043 no se podía usar.

## Decisión

1. **Dos tipos de token, un solo cliente (`infra/instagram/graph.ts`).** El prefijo decide el host: `EAA…` → `graph.facebook.com/v23.0` (Facebook Login); `IG…` → `graph.instagram.com`. Si el prefijo no es concluyente se prueba primero Instagram y, ante 190/400, se reintenta una vez contra Facebook; el que responde queda como el de ese cliente. Un token realmente inválido sigue dando el error del host esperado.
2. **Cuenta con Facebook Login:** `/me/accounts?fields=id,name,instagram_business_account{id,username}` (token de usuario) o `/me` (token de Página); se usa la cuenta de Instagram de la primera Página que la tenga y las demás se informan (`igUserId` en `GraphOptions` permite elegir otra; la interfaz de selección queda pendiente). Publicaciones: `/{ig-user-id}/media` con los mismos campos. Sin cuenta vinculada: error claro con los permisos a pedir (`instagram_basic`, `pages_show_list`, `pages_read_engagement`), no «venció».
3. **Hashtag público (solo Facebook Login):** `ig_hashtag_search` + `recent_media` como mejora opcional. Si falla (falta «Instagram Public Content Access») la sincronización de la cuenta sigue y se informa en `warnings`/`onWarning`. Con token de Instagram no existe esa API: el filtro sigue siendo por la leyenda de las publicaciones propias.
4. **Renovación:** `IG…` con `refresh_access_token`; `EAA…` con `fb_exchange_token` (hacen falta App ID y App Secret; sin ellos la renovación se omite con `needs-app-credentials` y hay que generar otro token antes de que venza).
5. **«Probar conexión» paso a paso (`POST /integrations/instagram/test`):** responde `steps: [{ id: token|identity|media|hashtag, label, status: ok|warn|fail|skipped, detail }]` con el código y el mensaje de Meta (sin el token); corta en el primer fallo. Avisa de espacios en el token, cuenta personal, varias cuentas y hashtag sin coincidencias. La pantalla lista cada paso.
6. **Carga manual por enlace, un solo campo:** si el enlace es de instagram.com (`/p/`, `/reel/`, `/tv/`, con `?igsh=` o sin barra) se normaliza por su código corto y se resuelve con la API oficial (primero entre lo ya cargado; si no, `findMediaByPermalink` recorre hasta ~500 publicaciones; para carruseles sin `media_url` se usa el primer hijo). **No se raspa instagram.com** (muro de inicio de sesión y términos de uso). Si no se encuentra o no hay cuenta conectada, la publicación queda sin imagen y al aprobar se ofrece **subir la imagen desde el equipo** (se aprueba y se sube la portada en un paso) o **publicar sin imagen** (`imageProblem: 'missing'`). Si el enlace NO es de Instagram se toma como la dirección de una imagen (con los mensajes por causa de ADR-043). La leyenda y la fecha pasan a ser opcionales cuando se resuelven solas; lo escrito a mano manda. Si la API la encontró se guarda con su id (la sincronización no la duplica). La respuesta incluye `resolution: { source, imageFound, reason? }`.

## Qué probar a mano con credenciales reales

(a) «Probar conexión» con el token `EAA`: debe mostrar la Página y la cuenta; si falla, el paso y el código de Meta. (b) Sincronizar. (c) Cargar a mano pegando el enlace de una publicación reciente: debe traer imagen y texto. (d) Con un enlace antiguo o de otra cuenta: debe ofrecer subir imagen o publicar sin imagen. (e) Hashtag público: depende de que Meta apruebe «Instagram Public Content Access».

## Consecuencias / pendientes

Verificado contra respuestas simuladas y la documentación pública de Meta; no hay credenciales reales en el entorno. Pendiente: selector de cuenta cuando el token ve varias Páginas; guardar la cuenta elegida. Tests: `test/unit/instagram-facebook.test.ts`, `test/api/social-manual-link.test.ts`.
