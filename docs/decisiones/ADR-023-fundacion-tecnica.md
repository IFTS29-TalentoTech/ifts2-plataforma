# ADR-023 · Decisiones de la fundación técnica

Estado: Propuesta (implementada). Elegí lo más simple y reversible.

| Tema                                                                 | Decisión                                                                                                                                                                                                                        | Motivo                                                                                                |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Paquete `@ifts2/shared`                                              | Se consume como **código fuente TS** (`main: src/index.ts`); web con `transpilePackages`; API con `tsup` que lo empaqueta (`noExternal`)                                                                                        | Sin paso de build previo en desarrollo ni pruebas; sin dist desactualizado                            |
| API en ESM                                                           | `"type": "module"`, `tsx` en desarrollo, `tsup` (entradas `server.ts` y `modules/*/index.ts`, con `splitting`) en producción                                                                                                    | El autodescubrimiento de módulos funciona igual en `src/` y en `dist/`                                |
| Autodescubrimiento                                                   | `src/routes.ts` lee `src/modules/*/index.ts` y monta `{ mountPath, router }` bajo `/api/v1`. `createApp()` es **asíncrona**                                                                                                     | Agregar un módulo no edita archivos compartidos (4 agentes en paralelo)                               |
| Contexto                                                             | Servicios en `req.ctx` (prisma, storage, `getMailer()`, `getInstagramClient()`, limitadores), no singletons                                                                                                                     | Las pruebas reemplazan cualquier servicio por un doble                                                |
| Express 5, Prisma 6 (`prisma-client-js`), Tailwind 3, Next 15, zod 3 | Versiones estables con el ecosistema probado                                                                                                                                                                                    | Prisma 7/Tailwind 4 cambian la configuración; no aportan al MVP                                       |
| Contraseñas                                                          | `@node-rs/argon2` (argon2id por defecto, binarios precompilados, funciona en Windows)                                                                                                                                           | ADR-06                                                                                                |
| Rate limit                                                           | `express-rate-limit` en memoria, instancia por app. Login: 5 **fallidos** / 15 min por IP y por correo                                                                                                                          | Suficiente para una sola instancia; con varias instancias usar un store compartido (pendiente DevOps) |
| CSRF                                                                 | `SameSite=Lax` + `Origin` debe ser `APP_ORIGIN`/`API_ORIGIN` si viene; sin `Origin` (curl, pruebas) se permite                                                                                                                  | Los navegadores siempre envían `Origin` en peticiones cruzadas                                        |
| Cookie `Secure`                                                      | Solo si `APP_ORIGIN` es `https://` (en `http://localhost` el navegador la descartaría en algunos casos)                                                                                                                         | En producción es HTTPS, por lo tanto Secure                                                           |
| Web -> API                                                           | El navegador llama a `/api/v1/*` en su propio origen y Next lo reenvía (`rewrites`) a `API_ORIGIN`; el servidor llama directo y reenvía la cookie                                                                               | Cookie de primer nivel, sin CORS ni problemas de dominios en el hosting                               |
| `/panel/*`                                                           | `middleware.ts` (sin cookie -> `/panel/login`) + `requireSession()` en `panel/(shell)/layout.tsx` + la API en cada endpoint                                                                                                     | Defensa en capas; el login queda fuera del grupo `(shell)`                                            |
| Puerto web                                                           | `next dev` usa `PORT` (por defecto 3000). En este equipo el 3000 puede estar ocupado: `PORT=3100 pnpm --filter @ifts2/web dev` y ajustar `APP_ORIGIN`                                                                           | No se tocan procesos ajenos                                                                           |
| Ciclo público único                                                  | Índice único parcial en la migración inicial (`WHERE "publicCurrent" = true`) + regla en servicio                                                                                                                               | Imposible tener dos ciclos públicos aun con un error de código                                        |
| Esquema Prisma                                                       | Enums en varias líneas (Prisma no admite una línea); se agregan `User.mustChangePassword`, `User.updatedAt`, `ContactMessage.mailSent`, `IntegrationConfig`, índices y `onDelete` (`Session` cascade, `AuditLog.user` set null) | La spec original no validaba y faltaban esos campos                                                   |
| Archivos locales                                                     | `LocalDiskStorage` guarda en `uploads/` y sirve con `GET /api/v1/files/<clave>?exp&sig` (HMAC)                                                                                                                                  | URL firmada de corta duración también en desarrollo                                                   |
| Cypress                                                              | Electron deprecado; correr con `ELECTRON_RUN_AS_NODE` sin definir (`env -u ELECTRON_RUN_AS_NODE`) si el entorno lo define (VS Code / Claude)                                                                                    | Sin esa variable el binario falla con "bad option: --smoke-test"                                      |
