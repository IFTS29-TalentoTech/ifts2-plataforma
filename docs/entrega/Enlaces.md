## Para empezar rápido

1. Instalá Node 24, pnpm 11 y Docker Desktop.
2. Seguí la sección **2. Instalación y puesta en marcha** del Manual Técnico (seis comandos).
3. Ingresá al panel con `admin@ifts2.local` / `Cambiame-123!` (credenciales de demostración).

## Contenido de esta documentación

- **Parte I · Manual Técnico**: instalación, arquitectura, estructura, base de datos (DER, tablas y relaciones), configuración, componentes, errores y validaciones, pruebas y limitaciones.
- **Parte II · Manual de Usuario**: uso del sitio y del panel paso a paso con capturas, operaciones de datos (CRUD) y mensajes frecuentes.
- **Parte III · Evidencias de pruebas y CRUD**: tres pruebas unitarias y dos de integración con su salida real, resumen de todas las suites y matriz de CRUD.
